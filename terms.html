ReelCommenter 서비스 약관

최종 업데이트: 2026-09-29

1. 서비스 목적

ReelCommenter는 사용자가 본인이 소유하거나 관리하는 Instagram Professional 계정을 관리하기 위한 개인용 도구입니다.

2. Instagram API 사용

ReelCommenter는 Meta가 공식적으로 제공하는 Instagram API를 우선 사용합니다.

비공식 로그인 자동화, CAPTCHA 우회, 플랫폼 보안 우회 또는 탐지 회피 기능을 제공하지 않습니다.

3. 계정 관리 책임

사용자는 ReelCommenter에 연결하는 Instagram 계정에 대한 적절한 소유권 또는 관리 권한을 보유해야 합니다.

4. API 제한

Meta 또는 Instagram API에서 지원하지 않는 기능은 ReelCommenter에서도 제공되지 않을 수 있습니다.

5. 서비스 변경

Meta 또는 Instagram API의 정책, 기능 또는 권한이 변경되는 경우 ReelCommenter 기능도 변경될 수 있습니다.
