ReelCommenter 개인정보처리방침

최종 업데이트: 2026-09-29

1. 서비스 개요

ReelCommenter는 한 명의 사용자가 본인이 소유하거나 관리하는 Instagram Professional 계정들을 관리하기 위한 개인용 로컬 도구입니다.

ReelCommenter는 Meta가 공식적으로 제공하는 Instagram API를 통해 승인된 계정의 Instagram 데이터에 접근합니다.

2. 처리할 수 있는 정보

ReelCommenter는 기능 수행을 위해 다음 정보를 처리할 수 있습니다.

  • Instagram 사용자 ID 및 사용자 이름
  • Instagram Professional 계정의 기본 계정 정보
  • Instagram 미디어 ID
  • Reel의 캡션, 미디어 유형, 링크 및 게시 시각
  • Instagram API가 허용하는 범위의 댓글 정보
  • Instagram API 인증을 위해 필요한 액세스 토큰

3. 정보 이용 목적

수집 또는 처리되는 정보는 다음 목적에만 사용됩니다.

  • 사용자가 관리하는 Instagram 계정 인증
  • 대상 Reel 식별 및 조회
  • Reel 관련 정보 분석
  • 댓글 조회 및 관리 기능 제공
  • Instagram API 기능 지원 여부 확인
  • ReelCommenter 기능 제공 및 오류 진단

4. 정보 저장

ReelCommenter는 현재 개인 개발 및 API 기능 검증 단계의 로컬 도구이며, 별도의 공개 SaaS 사용자 데이터베이스를 운영하지 않습니다.

인증정보와 개발 과정에서 생성된 데이터는 운영자가 사용하는 로컬 개발 환경 또는 개발 도구에 저장될 수 있습니다. 액세스 토큰이나 비밀키는 이 공개 웹사이트에 저장하지 않습니다.

5. 정보 판매

ReelCommenter는 Instagram 사용자 데이터를 판매하지 않습니다.

6. 제3자 서비스

ReelCommenter는 Instagram 기능 제공을 위해 Meta Platforms의 Instagram API를 사용합니다.

현재 API Capability Spike 단계에서는 Instagram 데이터를 별도의 AI 서비스에 자동 전송하지 않습니다. 향후 외부 AI 서비스 사용 방식이 변경되는 경우, 실제 운영 전에 본 개인정보처리방침을 업데이트합니다.
